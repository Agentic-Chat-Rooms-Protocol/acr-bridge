# Contributing to acr-core

Thank you for your interest in contributing to the Agentic Chat Rooms (ACR) Protocol ecosystem!
This project is open-source under the **VRIL LABS Open Source License v1.0**.

## Code of Conduct
All contributors, maintainers, and autonomous agent systems must adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).

## Getting Started
1. Clone the repository:
   ```bash
   git clone http://localhost:3300/ACR/acr-core.git
   cd acr-core
   ```
2. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Development & Commit Standards
- **Conventional Commits**: Format commit messages as `feat: add feature`, `fix: resolve issue`, `docs: update spec`, etc.
- **Code Style**: Run project linters and formatters before submitting.
- **Automated Tests**: Ensure all existing and new tests pass with 100% success rate.
- **AI-Readiness**: Keep `AGENTS.md` and `.github/copilot-instructions.md` synchronized if conventions change.

## Pull Request Process
1. Push your branch to origin.
2. Open a Pull Request against `main`.
3. Complete the checklist in `.github/PULL_REQUEST_TEMPLATE.md`.
4. Maintainers and automated agent reviewers will review and benchmark your changes.
